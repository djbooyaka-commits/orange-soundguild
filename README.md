# Orange Sound Guild

"Create a music streaming web app with a light-themed, modern SoundCloud aesthetic using an orange and dark gray accent color scheme. Build a top navbar with a search bar and a prominent 'Upload' button. The home feed should display a chronological grid of 'Recent Uploads'. Include a persistent bottom media player bar that tracks audio playback state dynamically across the site."
